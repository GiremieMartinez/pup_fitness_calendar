# Clarity Market

An HCI-optimized marketplace frontend prototype built with React, TypeScript, Vite, and Tailwind CSS.

The app redesigns marketplace browsing around:

- persistent navigation and filters
- faceted search with removable active filters
- consistent product cards and commerce-only content
- visible loading, success, and error feedback
- mobile-first responsive navigation
- accessible touch targets, labels, keyboard focus, and contrast-conscious colors

## Scripts

```bash
npm run dev
npm run build
npm run typecheck
```
